# ⚖️ Calculadora de IMC

Uma calculadora de Índice de Massa Corporal (IMC) simples, responsiva e moderna, desenvolvida com HTML5, CSS3 e JavaScript puro. O projeto conta com uma interface limpa inspirada no portal ABESO, estilizada com uma paleta de cores em tons pastel de roxo e lilás.

## 🚀 Funcionalidades

- **Cálculo em Tempo Real:** Calcula o IMC instantaneamente ao clicar no botão.
- **Classificação Completa:** Exibe os resultados baseados na tabela oficial para adultos:
  - Baixo peso, Peso normal, Sobrepeso e Níveis de Obesidade (I, II e III).
- **Design Responsivo:** Adaptado para telas de computadores, tablets e smartphones.
- **Interface Intuitiva:** Seletores de público (Adulto/Criança) e sexo (Homem/Mulher) para melhor experiência do usuário.

## 📁 Estrutura do Projeto

O projeto está organizado de forma modular para facilitar a manutenção do código:

```text
├── index.html     # Estrutura lógica e elementos da página
├── style.css      # Estilização visual 
└── script.js      # Lógica do cálculo de IMC e validações
```
