### 💚 Billie Eilish Fan Page

Um site moderno e responsivo dedicado à cantora **Billie Eilish**, desenvolvido para estudo de design e desenvolvimento web. 

### 🚀 O que foi feito

* **Navbar:** Menu com linha animada ao passar o mouse.
* **Discografia & Prêmios:** Páginas organizadas com CSS Grid e efeitos de brilho flutuante.
* **Indicações:** Guia de músicas separado por "vibes" musicais para novos ouvintes.
* **Estética:** Fundo escuro misturando o clássico verde neon com o azul do álbum *HIT ME HARD AND SOFT*.

### 🛠️ Tecnologias

* HTML5
* CSS3 (Flexbox, Grid e Animações)
* Google Fonts
